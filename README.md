# JIMIN Portfolio

컴퓨터공학을 전공하며 임베디드 시스템과 On-Device AI 분야에 관심을 가지고 있습니다.

개인 프로젝트와 개발 경험을 정리한 포트폴리오 웹사이트입니다.

## Portfolio

**Website:** https://Jimin-K04.github.io/

## About

임베디드 시스템, AI, 로보틱스 등 다양한 분야에서 진행한 프로젝트와 개발 경험을 소개합니다.

주요 프로젝트:
- **On-Device AI** — MCU 기반 AI 추론 및 CPU/NPU 성능 평가
- **UGV Robot** — RTOS 기반 정찰 로봇 제어 시스템
- **Drilling** — Unity 기반 2D 게임 개발 및 출시
- **Galmaegi** — 부산 특화 대화형 내비게이션 서비스

## Tech Stack
